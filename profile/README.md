# Repositorio Vacones
 
El proyecto estima la condición corporal (BCS) de vacas a partir de fotografías traseras capturadas en iPhone.
 
## Repositorios
 
El proyecto se dividió en dos repositorios:
 
| Repositorio | Contenido |
|---|---|
| **Documentación-VC** | Documentación del proyecto correspondiente a la metodología CRISP-DM |
| **Modelos** | Código de los modelos |
 
### Documentación
 
Contiene los entregables de cada fase de CRISP-DM:
 
1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
5. Evaluation
6. Deployment
### Modelos
 
Contiene el código para entrenar, evaluar y hacer predicciones con los modelos del proyecto.
